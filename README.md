# Menswear E-Commerce Website

A modern and responsive e-commerce website developed for a menswear shop.

## Features

- Responsive design for mobile and desktop
- Product listing and categories
- Product details
- Shopping cart and wishlist
- Checkout system
- User authentication
- Admin dashboard
- Product and category management
- Order management

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git & GitHub

## Future Enhancements

- Online payment integration
- WhatsApp order automation
- AI customer chatbot
- Stock management
- Order tracking
- AI-based product recommendations
